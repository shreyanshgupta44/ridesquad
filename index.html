How to install

  1. Tap Download for Android above.
  2. Open the downloaded RideSquad.apk.
  3. If Android asks, allow installing apps from your browser (Settings → Allow from this source).
  4. Tap Install, then open RideSquad.
  5. Open it once, close it fully, and open it again to get the latest version.
